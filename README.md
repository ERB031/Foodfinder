# Foodfinder

A mobile-first platform where culinary professionals review restaurants and dishes. Built with React Native (Expo), Node.js, and PostgreSQL.

## Structure

- `main/` — Application source code (mobile app, backend API, shared types)
- `Claude/` — Architecture docs, feature specs, and planning materials

See `CLAUDE.md` for development conventions and `Claude/` for detailed architecture documentation.

## Status

Initial scaffolding. No runnable code yet — see `Claude/FEATURES.md` for the development roadmap.
